# משימת בסיס ירח 🌙

משחק כיתה חי לטבלטים, לכיתה ה׳, לסיום המפגשים על הירח. כל ילד משחק לבד ומתכנן בסיס קבע על הירח בשבעה שלבים.

- מסך המורה (להקרנה): https://technodahadera.github.io/moon-base/teacher.html
- התלמידים: https://technodahadera.github.io/moon-base/ (או סריקת ה-QR שעל מסך המורה)

המאגר הזה מכיל רק את דפי המשחק. השרת שמחבר את הטבלטים למסך המורה ושומר את ההתקדמות רץ בכתובת https://moon-base.sites.tab.bot, וקוד המקור המלא נמצא במאגר הפרטי moon-base-source.
